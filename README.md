## ICTC 일정 · 주요업무 (웹앱 초안)

팀원이 브라우저에서 일정과 업무를 직접 추가·수정·삭제할 수 있는 보드입니다.

- 일정표: 날짜별 그룹, 오늘 강조, 구분(교육/회의 …) 필터
- 주요업무: 상태(예정/진행중/완료/보류) 필터, 기한 지연 표시, 상태 배지 클릭으로 상태 순환
- PC: 좌측 고정 사이드바(요약·필터·버튼) + 우측 콘텐츠 2단, 1400px 이상에서 업무 3열
- 모바일: 바텀시트 입력, 플로팅 추가 버튼
- 단축키: `N` 새 항목, `1`/`2` 탭 전환, `Esc` 닫기
- 다크모드 자동 대응

### 데이터 저장 방식 (중요)

GitHub Pages는 정적 호스팅이라 서버 저장소가 없습니다. 현재 초안의 저장 구조는 다음과 같습니다.

1. 처음 열면 저장소의 `ictc/data/schedule.json`, `ictc/data/tasks.json`을 읽어 표시합니다 (팀 공통 기본값).
2. 브라우저에서 추가·수정한 내용은 **그 브라우저(localStorage)에만** 저장됩니다. 다른 팀원에게는 보이지 않습니다.
3. 팀 전체에 반영하려면 **JSON 내보내기**로 받은 파일을 `ictc/data/`의 같은 이름 파일에 덮어써서 커밋합니다.
4. 팀원은 ⋮ 메뉴 → **기본값으로 복원**을 누르면 저장소의 최신 데이터를 다시 불러옵니다.

실시간 공동 편집이 필요하면 백엔드(예: Supabase, Firebase)나 Google Sheets 연동이 필요합니다.

### JSON 형식

```json
// schedule.json 항목
{ "id": "s001", "date": "2026-10-22", "start": "09:00", "end": "12:00",
  "title": "일정 제목", "place": "장소", "owner": "담당", "tag": "교육", "note": "메모" }

// tasks.json 항목
{ "id": "t001", "category": "교육운영", "title": "업무명", "status": "진행중",
  "due": "2026-11-14", "owner": "담당", "detail": "상세 내용" }
```

`status`는 `예정` / `진행중` / `완료` / `보류` 중 하나. `id`가 없으면 자동 생성됩니다.

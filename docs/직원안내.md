# 직원 안내 (카톡·메신저 공유용)

한 번에 다 보내기 길면 "5단계"만 먼저 보내고, "자주 묻는 것"은 답글로 보내세요.

**SAIL:41 — 지휘역량강화센터 일정·업무 보드**
https://kwonyujin119.github.io/test2/

**1. 들어가기**
링크를 열고 팀 PIN **○○○○** 을 넣어요. 기기마다 한 번만 넣으면 돼요.
카톡·네이버 앱 안에서 열렸으면 "크롬으로 열기" 버튼을 눌러 주세요.

**2. 탭 세 개**
Schedule = 일정표 · Attention = 주요업무 · Individual Log = 내 업무
탭을 한 번 더 누르면 달력으로 바뀌어요(세 탭 모두). 주요업무·내 업무는 기한 날짜에 표시돼요.

**3. 일정·업무 넣기**
오른쪽 아래 **+** 를 눌러 추가해요. 누구나 추가·수정·삭제할 수 있어요.
잘못 지웠으면 담당자에게 말해요. 30일 안이면 복구돼요.
일정의 **시간**을 누르면 날짜·시간만, **제목**을 누르면 내용을 고쳐요.
구분에 "주요업무"를 고르면 Attention 탭에도 같이 올라가요.

**4. 내 업무(Individual Log)**
행정전화 **뒤 4자리**와 내가 정한 **비밀번호 4자리**를 넣어요. 처음이면 "새로 등록할까요?" 에 **확인**을 누르면 끝이에요.
이름은 들어간 뒤 **⋮ → 내 이름 변경**에서 정해요(업무 카드의 담당자로 보여요). 내 업무는 나만 볼 수 있어요.
비밀번호를 잊으면 담당자에게 초기화를 부탁해요.
엑셀로 정리해 둔 업무 목록이 있으면 **⋮ → 엑셀로 개인업무 가져오기**로 한 번에 넣어요.

**5. 41망(팀 대화)**
오른쪽 위 **말풍선**을 누르면 부서 톡방 목록이 떠요(지휘역량강화센터·교육지원과·교육기획과·훈련운영과).
부서 이름 오른쪽 말풍선을 누르고 **입장코드 4자리**를 넣어요. 코드는 담당자에게 받아요. 한 번 넣으면 기억돼요.
내 업무에 들어가 있으면 그 이름으로, 아니면 처음 한 번 이름을 정해요.
새 글이 있으면 말풍선과 톡방 이름 옆에 숫자가 떠요. 내 글은 **삭제**로 지울 수 있어요. 톡방마다 최근 300개까지만 남아요.
사진·파일은 입력창 왼쪽 **+** → 카메라·갤러리·파일. 고른 사진은 위 줄에 번호로 보이고 **전송**을 누르면 올라가요(한 번에 100MB·10개). 사진을 누르면 펜·지우개·자르기로 고칠 수 있어요.
PC 에서는 캡처한 화면을 입력창에 **Ctrl+V** 로 붙여 넣어 보낼 수 있어요.
글이나 사진을 **우클릭(폰은 길게 누르기)** 하면 답장·이미지 복사·글 복사·공유·저장·삭제 메뉴가 떠요.

**6. 홈 화면에 추가**
들어가면 "홈 화면에 추가" 카드가 떠요. **추가하기**를 누르면 앱처럼 쓸 수 있어요.
카드를 놓쳤으면 오른쪽 위 **⋮ → 홈 화면에 추가**.

## 홈 화면 추가가 안 될 때 (브라우저별)

| 어디서 열었나 | 방법 |
|---|---|
| 크롬(안드로이드) | 오른쪽 위 ⋮ → **홈 화면에 추가** 또는 **앱 설치** |
| 삼성 인터넷 | 아래 오른쪽 ≡ → **현재 페이지 추가** → **홈 화면** |
| 네이버 웨일 | 아래 ≡ → **홈 화면에 추가** |
| 카카오톡 안에서 열림 | 들어가면 바로 뜨는 카드의 **브라우저로 열기**를 누르세요. 카톡 밖 브라우저(크롬·Safari)로 열리면서 설치 안내가 다시 떠요. 안 되면 ⋯ → **다른 브라우저로 열기**, 또는 안내창의 **주소 복사** 뒤 브라우저에 붙여 넣기 |
| 네이버 앱 안에서 열림 | 설치가 안 돼요. 화면의 **브라우저로 열기** 버튼 → 크롬이나 삼성 인터넷에서 다시 추가 |
| 아이폰 | Safari로 열고 아래 **공유**(네모에 화살표) → **홈 화면에 추가**. 카톡 안에서 열렸으면 오른쪽 위 ⋯ → **Safari로 열기** 먼저 |
| PC 크롬·엣지 | 주소창 오른쪽 끝 **설치** 아이콘 |

홈 화면 아이콘 이름은 **SAIL:41**, 그림은 인천소방학교 심벌이에요. PIN과 내 업무 로그인은 그대로 유지돼요.

## 자주 묻는 것

| 질문 | 답 |
|---|---|
| 자물쇠 화면이 또 떠요 | 브라우저 데이터를 지웠거나 PIN이 바뀐 거예요. 담당자에게 현재 PIN을 물어보세요. |
| 다른 사람도 내 일정을 고칠 수 있나요 | 네. 팀 PIN이 있으면 누구나 일정·주요업무를 고치고 지울 수 있어요. 지우기 전엔 한 번 더 확인해 주세요. 화면에서는 되돌릴 수 없어요. |
| 잘못 지웠어요 | 담당자에게 바로 알려 주세요. 30일 안이면 되살릴 수 있어요. |
| "비밀번호가 맞지 않아요" | 비밀번호 4자리를 다시 확인해요. 잊었으면 담당자가 초기화해 줘요. 전에 이름으로 들어가던 분도 담당자에게 새 비밀번호를 받으면 돼요. |
| 비밀번호를 바꾸고 싶어요 | 들어간 뒤 ⋮ → **내 비밀번호 변경**. |
| 이름이 잘못 등록됐어요 | 담당자가 사용자 관리에서 바로 고쳐 줘요. 업무는 그대로예요. |
| 같은 행정전화를 두 명이 써요 | 뒤 4자리는 한 사람만 쓸 수 있어요. 담당자에게 알려 주시면 다른 번호를 정해 드려요. |
| 특정 일정이 언제인지 찾고 싶어요 | 추가 **+** 버튼 왼쪽 **검색창**에 키워드를 넣어요. 두 단어를 띄어 쓰면 둘 다 들어간 것만 나와요. 맞는 일정이 노랗게 표시되고 "N건 · M일"로 날짜 범위를 알려 줘요. 달력으로 바꾸면 해당 날짜 칸이 금색이에요. |
| 화면을 더 넓게 쓰고 싶어요 | ⋮ → **넓게 보기**(PC는 요약 카드의 ⤢ 또는 W 키). 왼쪽 아래 **기본 보기**로 돌아와요. |
| 구분의 ICTC · 시민체험은 뭐예요 | 어느 팀 업무인지 표시예요. 일정·업무를 넣을 때 골라 두면 목록에서 주요업무 → ICTC → 시민체험 순서로 앞에 와요. |
| 노란 일정은 뭐예요 | 구분에 '주요업무'가 든 중요한 일정이에요. 목록·달력에서 ★ 와 금색으로 표시돼요. |
| 목록이 다 안 보여요 | 한 번에 10개씩 보여요. 목록 맨 아래 **‹ ›** 로 넘기거나 **5·10·15·20개씩**을 고르세요. |
| 화면이 안 바뀌어요 | 30초마다 자동으로 새로 받아요. 급하면 ⋮ → **서버에서 새로고침**. |
| 엑셀 업무 목록을 한 번에 넣고 싶어요 | Individual Log에 들어간 뒤 ⋮ → **엑셀로 개인업무 가져오기**. 업무명·기한·상태 열을 알아서 찾고, 미리보기에서 넣을 줄만 체크해요. 이미 있는 건 자동으로 빠져요. |
| 다른 폰·PC에서 내 업무를 보려면 | 그 기기에서 Individual Log 탭에 같은 뒤 4자리 + 비밀번호를 넣어요. 홈 화면에 설치한 앱도 처음 한 번만 넣으면 돼요. |
| 내 업무에서 나가려면 | Individual Log 화면 왼쪽(폰은 위쪽) 이름 카드의 **로그아웃**, 또는 ⋮ → 개인업무 로그아웃. |
| 뒤로가기를 눌렀는데 안 꺼져요 | 처음 화면에서 뒤로가기를 한 번 더 누르면 나가요. |
| 초록 테두리가 보여요 | 그 기기가 관리자 모드예요. 담당자 기기가 아니면 ⋮ → **관리자 모드 해제**를 눌러 주세요. |

아래 점선 안을 그대로 복사해 보내세요. `○○○○` 자리에 팀 PIN을 넣습니다. 41망 입장코드는 이 글에 적지 말고 부서별로 따로 알려 주세요.
한 번에 다 보내기 길면 "1~6"만 먼저 보내고, "자주 묻는 것"은 답글로 보내세요.

**SAIL:41 — 지휘역량강화센터 일정·업무 보드**

**1. 들어가기**
링크를 열고 팀 PIN **○○○○** 을 넣고 **들어가기**. 기기마다 한 번만 넣으면 돼요.
카톡 안에서 열렸으면 PIN을 넣은 뒤 아래에 뜨는 카드의 **설치하기**를 누르세요(크롬·Safari로 열리며 설치가 이어져요). 그냥 카톡 안에서 봐도 되지만 홈 화면 설치는 안 돼요.

**2. 탭 세 개**
Schedule = 일정표 · Attention = 주요업무 · Individual Log = 내 업무
탭을 **한 번 더** 누르면 달력으로 바뀌어요(세 탭 모두). 주요업무·내 업무 달력은 기한 날짜에 표시되고, 기한 없는 건 아래 "기한 미정" 줄에 모여요.
화면 위 **과 이름▾** 은 대시보드 선택이에요. 평소에는 "지휘역량강화센터(ICTC)" 그대로 두세요.

**3. 일정·업무 넣기**
오른쪽 아래 **+ 일정 추가 / + 업무 추가** 를 눌러 넣어요. 팀 PIN이 있으면 누구나 추가·수정·삭제할 수 있어요.
일정의 **시간**을 누르면 날짜·시간만(하루 전/뒤·일주일 뒤·종일), **제목**을 누르면 내용을 고쳐요. 수정 창의 **복사**는 내용은 그대로 두고 날짜만 새로 넣어요.
구분은 여러 개 고를 수 있고, **주요업무**를 고르면 Attention 탭에도 같이 올라가요(금색 ★). ICTC·지휘역량팀·시민체험팀을 고르면 목록 앞쪽에 와요.
**사진**을 붙일 수 있어요. 추가·수정 창 아래 **사진 첨부**(또는 캡처한 화면을 Ctrl+V, PC는 끌어다 놓기) → 저장하면 올라가요. 10장까지, 카드에 작은 사진으로 보이고 누르면 크게 열려요. 크게 본 화면에서 **오른쪽으로 밀면 다음**, 왼쪽으로 밀면 이전 사진이고, 오른쪽 위 **⋮** 로 41망·카톡 공유, 복사, 저장을 할 수 있어요.
지난 일정은 접혀 있어요. 목록 위 **지난 일정 N건 펼치기**로 봐요.
잘못 지웠으면 담당자에게 말해요. 30일 안이면 복구돼요.

**4. 내 업무(Individual Log)**
행정전화 **뒤 4자리**와 내가 정한 **비밀번호 4자리**를 넣고 **들어가기**. 처음이면 "아직 등록되지 않았어요 … 새로 등록할까요?" 창에 **확인**을 누르면 끝이에요.
등록 직후 "이름을 넣어 주세요" 창이 떠요. 본인 이름을 넣으면 업무 카드와 41망에 그 이름이 보여요. 건너뛰면 "직원 1234"로 남으니 나중에 **⋮ → 내 이름 변경**에서 바꿔 주세요.
내 업무는 나만 볼 수 있어요. 비밀번호를 잊으면 담당자에게 초기화를 부탁해요.
엑셀로 정리해 둔 목록이 있으면 **⋮ → 엑셀로 개인업무 가져오기**로 한 번에 넣어요.

**5. 41망(부서 톡방)**
오른쪽 위 **겹친 말풍선** 아이콘을 누르면 부서 톡방 목록이 떠요(지휘역량강화센터·교육지원과·교육기획과·훈련운영과).
부서를 누르고 **입장코드 4자리**를 넣어요. 코드는 담당자에게 받아요. 한 번 넣으면 기억돼요.
내 업무에 들어가 있으면 그 이름으로, 아니면 처음 글을 보낼 때 이름을 한 번 정해요.
새 글이 있으면 말풍선과 톡방 이름 옆에 숫자가 떠요. 글은 500자까지, 톡방마다 최근 300개까지만 남아요.
사진·파일은 입력창 왼쪽 **+** → 카메라·갤러리·파일. 고른 사진은 위 줄에 번호로 보이고 **전송**을 누르면 올라가요(한 번에 10개, 파일 하나는 50MB까지). 사진을 누르면 펜·지우개·자르기로 고칠 수 있어요.
PC에서는 캡처한 화면을 입력창에 **Ctrl+V**로 붙여 넣고, Enter로 보내요.
글이나 사진을 **길게 누르면(PC는 우클릭)** 답장·이미지 복사·글 복사·공유·사진 저장·삭제 메뉴가 떠요. 내 글은 **삭제**로 지울 수 있고, 자리에 "(삭제된 메시지)"로 남아요.

**6. 앱 설치(홈 화면에 추가)**
두 번째로 들어올 때 아래에 "SAIL:41 앱으로 설치" 카드가 떠요. **설치하기** 한 번이면 끝이에요(PC는 상단 **앱 설치** 버튼, 폰은 **⋮ → 앱 설치**).
- 안드로이드·PC: 바로 설치창이 떠요. **설치**를 누르면 홈 화면·바탕화면에 SAIL:41 아이콘이 생겨요.
- 카톡 안에서 열었을 때: **설치하기**를 누르면 바깥 브라우저로 열리고 설치가 자동으로 이어져요.
- 아이폰: 아이폰은 어떤 앱도 버튼 하나로 설치가 안 돼요. **설치하기**를 누르면 2단계 그림이 떠요 → 아래 가운데 **공유** → **홈 화면에 추가**.

## 앱 설치가 안 될 때

| 상황 | 방법 |
|---|---|
| 설치창이 안 뜨고 안내만 떠요 | 이미 설치돼 있을 가능성이 커요. 홈 화면(바탕화면)에서 SAIL:41 을 찾아보세요. 없으면 안내대로 브라우저 메뉴에서 **홈 화면에 추가** |
| 카톡에서 **설치하기**를 눌러도 그대로예요 | 카톡 오른쪽 아래 ⋯ → **다른 브라우저로 열기**(아이폰은 **Safari로 열기**) 한 뒤 다시 **설치하기** |
| 아이폰 | Safari 아래 가운데 **공유**(네모에 화살표) → **홈 화면에 추가** → 오른쪽 위 **추가** |

홈 화면 아이콘 이름은 **SAIL:41**, 그림은 인천소방학교 심벌이에요. 설치한 앱에서는 처음 한 번 팀 PIN과 내 업무 비밀번호를 다시 넣어야 할 수 있어요(아이폰은 항상). 그 뒤로는 기억돼요.

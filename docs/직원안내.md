처음 열면 자물쇠 화면이 뜹니다. 조회 PIN **○○○○** 을 넣고 "들어가기". 한 번 넣으면 그 폰·PC에는 다시 묻지 않습니다.

• **일정표** 탭: 센터 일정. 탭을 한 번 더 누르면 달력으로 바뀝니다.
• **주요업무** 탭: 팀 업무 현황. 상태·분류·담당자로 걸러 볼 수 있습니다.
• **개인업무** 탭: 본인 업무 메모. 행정전화번호 **뒤 4자리**와 **이름**만 넣으면 됩니다. 처음이면 자동 등록되고, 폰·PC 어디서든 같은 정보로 들어가면 같은 내용이 보입니다.

⚠️ 개인업무에는 비밀번호가 없습니다. 번호와 이름을 아는 사람은 볼 수 있으니 민감한 내용(인사·개인정보·비밀)은 적지 마세요.
✏️ 일정·주요업무를 고치려면 편집 PIN이 필요합니다. 담당자(권유진)에게 문의.

## 홈화면에 추가하기 (앱처럼 쓰기)

**아이폰(Safari)**: 주소를 Safari로 연 뒤 하단 가운데 **공유 버튼(네모에 화살표)** → 아래로 내려 **홈 화면에 추가** → 추가.
**안드로이드(Chrome)**: 오른쪽 위 **⋮** → **홈 화면에 추가**(또는 "앱 설치") → 추가.

홈화면에 인천소방학교 심벌 아이콘이 생깁니다. 조회 PIN과 개인업무 로그인도 그대로 유지됩니다.

## 자주 묻는 것

| 질문 | 답 |
|---|---|
| 자물쇠 화면이 또 떠요 | 브라우저 데이터를 지웠거나 PIN이 바뀐 경우입니다. 담당자에게 현재 PIN을 확인하세요. |
| "이 번호는 다른 이름으로 등록되어 있습니다" | 처음 등록할 때 쓴 이름과 다릅니다. 같은 이름으로 넣으세요. 오타로 등록됐다면 담당자가 고쳐 줍니다. |
| 다른 사람 일정을 잘못 고쳤어요 | 편집 PIN이 있어야 고쳐지므로 조회만 하는 분은 걱정 없습니다. 고친 분은 담당자에게 알려 주세요. |
| 화면이 안 바뀌어요 | 30초마다 자동 갱신됩니다. 급하면 ⋮ 메뉴 → "서버에서 새로고침". |
| 개인업무를 다른 기기에서도 보려면 | 그 기기에서 개인업무 탭에 같은 뒤 4자리 + 이름을 넣으면 됩니다. |
